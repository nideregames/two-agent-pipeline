## ПРАВИЛА

### Обязательные:
- Прочитай ограничения по области И глобальные ограничения ПЕРЕД началом работы
- Одна спека = одна сессия. Не делай лишнего за рамками задания.
- ВСЕГДА пиши отчёт, даже для тривиальных изменений
- **НЕ обновляй `state/active.md`** — это файл PM. Твоя задача: обновить статус спеки + написать отчёт.

### Без самодеятельности — КРИТИЧНО:
**Делай РОВНО то, что просят — не больше.** Если заметил что-то, что можно улучшить — **сообщи пользователю и жди подтверждения.** Не действуй по своему усмотрению.

### Когда что-то идёт не так:
- Спека противоречит реальности → зафиксировать расхождение, спросить пользователя
- Что-то сломалось → починить, задокументировать в отчёте, добавить в грабли
- Не удаётся завершить → поставить `blocked`/`partial`, объяснить в отчёте
