# Framework Templates

Каноничные шаблоны пайплайна. Не привязаны к конкретной предметной области.

Для адаптации под свой домен см. [docs/customization.md](../docs/customization.md).  
Для готового примера реализации см. [examples/dev-pipeline/](../examples/dev-pipeline/).

## Содержимое

| Шаблон | Назначение |
|--------|-----------|
| `spec-template.md` | Задание от PM к Исполнителю |
| `recon-template.md` | Задание на исследование (без изменений в проекте) |
| `session-template.md` | Отчёт Исполнителя после выполнения задания |
| `adhoc-template.md` | Отчёт по незапланированной задаче |
| `project-brief-template.md` | Описание проекта при инициализации |
| `entry-point-template.md` | Точка входа для Исполнителя (указатель на vault) |
