# Framework Templates

Каноничные шаблоны и инструкции пайплайна. Не привязаны к конкретной предметной области.

Для адаптации под свой домен см. [docs/customization.md](../docs/customization.md).  
Для готового примера реализации см. [examples/dev-pipeline/](../examples/dev-pipeline/).

## Содержимое

| Файл | Назначение |
|------|-----------|
| `pm-instructions.md` | **Инструкции для PM-агента** — как вести процесс, писать спеки, читать отчёты |
| `entry-point-template.md` | Точка входа для Исполнителя (указатель на vault + правила) |
| `spec-template.md` | Шаблон задания от PM к Исполнителю |
| `recon-template.md` | Шаблон задания на исследование (без изменений в проекте) |
| `session-template.md` | Шаблон отчёта Исполнителя после выполнения задания |
| `adhoc-template.md` | Шаблон отчёта по незапланированной задаче |
| `project-brief-template.md` | Шаблон описания проекта при инициализации |
